# Skills

이 디렉토리는 `nest-batch` 작업에 반복해서 적용할 repo-local skill 문서를 둡니다.

원칙:
- 스킬 본문은 한국어로 작성합니다.
- 코드 식별자, 패키지명, API 이름은 영어를 유지합니다.
- 역할 문서에서는 이 디렉토리의 `SKILL.md`를 상대 경로로 참조합니다.
- `nest-batch` 관련 작업에서는 이 디렉토리의 skill을 먼저 고려합니다.
- 자세한 예제나 긴 참고자료가 필요해지면 각 skill의 `references/`로 분리합니다.

초기 스킬:
- `nest-batch-architecture`
- `batch-runtime`
- `database-adapters`
- `orm-integrations`
- `testing`
- `public-api-docs`
- `commit-messages`
